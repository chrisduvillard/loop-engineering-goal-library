# Runtime control map

- Authority: approved contract fingerprint and mutation mode.
- Concurrency: exclusive expiring lease.
- State: canonical JSON, generated Markdown views.
- Continuity: Goal Kernel plus active pointer and next action.
- Completion: acceptance statuses, verifier exit code, evidence envelope.
- Read-only safety: Git worktree mutation check.
- High assurance: independent held-out verifier and anti-cheat review.
- Distribution: reference-closed deterministic archives and checksums.
