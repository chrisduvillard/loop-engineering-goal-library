# Deterministic Verification Gates

The implementation is accepted at repository level only when all of the following pass:

- Python compilation and full unit/adversarial suite.
- Goal launcher, generated documentation, and compact reference synchronization.
- `goalctl` lifecycle, lease, mutation, and false-completion self-test.
- Behavioral evaluation harness self-test.
- Goal archive and tooling-contract self-tests.
- Complete repository validator.
- Deterministic package rebuild comparison.
- Skills CLI discovery for both explicit skills.

Live host behavior is a separate pre-1.0 gate.
