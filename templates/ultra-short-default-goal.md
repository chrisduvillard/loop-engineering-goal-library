# Ultra-Short Default `/goal`

Use this only when `goal-engine` is installed and `GOAL.md` is already approved and complete.

```text
/goal Follow goal-engine to complete GOAL.md using its profile, assurance overlays, and project harness. Stop only when every acceptance item passes with surfaced evidence, or when a contract-defined blocker, approval boundary, budget, material goal drift, or two-cycle stall applies; preserve reusable state and leave a restartable handoff.
```

When no approved Goal Contract exists, use a zero-friction launcher under [`goals/`](../goals/) instead; it activates both `shape-goal` and `goal-engine` and requires no placeholder replacement.
